Privacy Policy

System Toolbox is an open-source, offline Windows maintenance toolbox. This page explains what data the application stores and how it is handled.

What data is stored

System Toolbox stores the following data locally on your device, under %LOCALAPPDATA%\SystemToolbox:

  • Runtime logs — console session history and operation records
  • Background task queue state — pending/completed task entries and their output
  • Configuration backups — snapshots of settings before system-modifying operations
  • Optional add-on data — cached metadata for DiskTool DLC and volume mount state

What is NOT collected

  • No telemetry, analytics, or usage tracking
  • No crash reports are transmitted
  • No personal information is collected
  • All downloads (updates, fastdl, etc.) go directly from the source you choose — no proxy, no intermediate server operated by the developer

Data transmission

System Toolbox does not send any data to the developer. The only network traffic the application generates is:

  • Downloading updates from the official GitHub Releases page
  • Running winget commands on your behalf (which contact Microsoft's package repositories)
  • FastDL downloads from URLs you provide

Data retention and deletion

All data persists locally until you delete it. To fully remove all application data, simply delete the folder %LOCALAPPDATA%\SystemToolbox. Uninstalling the portable build requires no further cleanup — the executable is self-contained.
