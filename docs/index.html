免费开源 · Windows 10 / 11 · v1.9

常用系统操作，
集中到一个工具箱。

System Toolbox 将维护、安装、下载、音乐转换和磁盘管理集中在同一个控制台入口。后台队列让独立任务运行时，你还能继续操作。

下载 v1.9 完整包 查看源码与使用说明 ↗
wingetwinget install system-toolbox
npmnpm install -g system-toolbox

npm 已正式收录，可直接 npm install -g system-toolbox 安装；winget 官方收录审核中，通过前可先下载 ZIP 解压使用。

安装不用一直等

winget 等独立命令可加入后台队列；支持并发、优先级、暂停、继续和独立日志。安装后刷新常用开发工具的 PATH。

下载与音频处理

集成 fastdl 多线程和断点下载；支持 NCM、QMC、KGM、KWM 等常见音乐文件转 MP3，转码需要 FFmpeg。

磁盘工具按需装载

DiskTool DLC 下载后校验；提供 ISO/VHD/VHDX 与卷挂载入口。开机磁盘检查设置仅作用于选择的卷。

解压完整包后运行

保留同目录的三个 EXE：主程序、music-converter 和 fastdl。系统维护功能需要管理员权限。发行页提供 SHA256 校验清单；程序按 EXE 哈希检查更新。

部分音乐文件需要对应密钥，新版厂商格式可能不兼容。磁盘写入和修复前请备份重要数据。DiskTool 的部分功能需要配套资源。
